#### 2. What is Complexity Analysis ?

* It means, how much time or work, how much memory usage need to analyze.
* It has five Concepts;

##### 1. Time Complexity:

* how the running time of an algorithm grows when the input size increases.

##### 2. Space Complexity:

* how much memory usage grows when the input size increases.

##### 3. Big - O:

* Upper Bound
* Miximum Growth
* Worst case

##### 4. Big - Ω (Omega):

* Lower Bound 
* Minimum Growth
* Best case

##### 5. Big - Θ (Theta):

* Tight Bound
* Exact Growth
* Neither best case nor worst case
